# Vora Climate Control UI

A modern Flutter single-screen climate control interface built as part of the Vora Mobile Development Internship Phase 2 task.

## Preview

This project simulates a smart room climate controller with interactive UI components and smooth state-based behavior.

## Features

- Room climate dashboard UI
- Current temperature & humidity cards
- Interactive temperature control dial
- Increase / decrease target temperature
- Power ON/OFF system toggle
- Fan speed selector
  - Low
  - Medium
  - High
- Disabled UI state when power is turned off
- Smooth animations and transitions
- Clean and modular project structure

## Tech Stack

- Flutter
- Dart

## State Management

The project uses Flutter's built-in `setState` for lightweight local state management.

## How to Run

1. Clone the repository

```bash
git clone <https://github.com/Filx2001/vora-climate-ui.git>
```

2. Navigate to the project folder

```bash
cd vora_livingroom
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the app

```bash
flutter run
```
